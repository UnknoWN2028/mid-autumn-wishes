# 月下寄相思

可直接部署到 GitHub Pages 的中秋互动祝福网页。原生 HTML、CSS、JavaScript，无需构建和后端。

## 功能

专属页面：

- `sansan.html`：送给三三，白色月光主题，祝福「愿你自在明亮」。使用仓库内的《水边的阿狄丽娜》音频，打开信件时开始播放，右上角可暂停或继续，播放完会循环。这首是器乐曲，页面中的句子为原创祝福，不标作歌词。
- `mimi.html`：送给米米，深蓝金色夜色主题，祝福「愿你与星光同在」，可在站内打开《夜之乐章》的官方歌曲播放器。
- `index.html`：网站首页直接呈现三三的专属祝福；`sansan.html` 保留相同内容的独立地址。

分享时分别发送对应的专属页面地址。每个专属页面只展示该收件人的内容，支持拆信、点月亮读悄悄话、放灯、抽签和下载贺卡。文案集中在 `profiles.js`，专属样式在 `personal.css` 和 `duet.css`。三三页的本地音频复用自用户提供的 `sansi-three-months` 仓库；米米页使用官方嵌入播放器，播放需要访问 YouTube；米米页右上角的“听见月色”是网页自行生成的轻音乐。网站为公开静态页面，独立入口不等于访问权限隔离。

- 自定义收件人、署名、祝福，生成专属贺卡
- 分享携带祝福的链接（内容存于 URL hash，不写入数据库）
- 下载 PNG 祝福卡片
- 放飞孔明灯、抽取月签、手动开启轻音乐
- 手机适配、键盘访问、减少动态效果偏好支持

## 本地预览

在项目目录运行 `python -m http.server 8080`，访问 http://localhost:8080。

## GitHub Pages

将本目录推送到 GitHub 仓库的 `main` 分支，然后在仓库 Settings → Pages → Build and deployment 选择 Deploy from a branch，分支选择 `main`、目录选择 `/ (root)` 并保存。

发布地址为 `https://你的用户名.github.io/仓库名/`。页面不依赖绝对资源路径，可部署到子目录。

Google Fonts 用于可选中文字体，无法加载时自动使用系统宋体。其他视觉资源与音乐均由本地代码生成。祝福仅保存在分享链接中，拿到链接的人可以查看；放灯数量仅统计本次页面打开期间的操作。
